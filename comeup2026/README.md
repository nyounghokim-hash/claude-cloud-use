# COMEUP 2026 참가·전시 기업 조사

컴업(COMEUP) 2026: 2026년 12월 9~11일, 코엑스 C홀. 일반 전시기업 명단은 2026-10-12 기준 미공개.

## 파일
- `comeup_stars_2026_companies.csv`: 컴업스타즈 2026 최종 선발 30개사 (6개 트랙, 본행사 부스 확정)
- `comeup_exhibitors_all.csv`: 통합본. `구분` 컬럼으로 나뉨
  - `2026 컴업스타즈(부스 확정)`, `2026 참가 발표`, `2026 확정 참가(주최·주관)`, `2026 컴업하우스 파트너`, `2026 자문위원 소속`
  - `2025 스타트업 전시`, `2025 대기업·기관 전시`, `2024 스타트업 전시`: 지난 행사 참가 기업 (재참가 가능성이 있는 참고 명단)

- 이메일은 공개된 회사 대표·문의용 주소만 넣었음. 개인 이름 형태의 주소는 제외했고, 추측해서 만든 주소는 없음.
